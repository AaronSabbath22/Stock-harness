# Run stock-harness on your iPhone (Python Code Pad)
## Route 1 (easiest): copy and paste one file
1. Open phone_single_file.py from the chat and copy ALL of the text.
2. In Python Code Pad, make a new file, paste, and tap Run.
3. You should see two PASS lines and "All good! 2/2 sessions pass."
It needs no files, folders, pip, or internet.
## Route 2: the zip (for apps that handle folders, like Pythonista, Pyto, or a-Shell)
1. In the chat, tap stock-harness-phone.zip, then Share > Save to Files.
2. In the Files app, tap the zip to unzip it into a stock-harness folder.
3. Open that folder in your Python app, open run_on_phone.py, and tap Run.
   (a-Shell: cd into the folder, then type python3 run_on_phone.py)
Learning only. Never trades.
