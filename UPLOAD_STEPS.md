# Put stock-harness on GitHub (from an iPhone)
1. Unzip first: save stock-harness-github.zip to the Files app, then tap it once. You get a stock-harness folder.
2. In Safari, go to github.com and sign in to your own free account (or sign up at github.com/signup).
3. If buttons are missing, tap the "aA" button in the address bar, then "Request Desktop Website".
4. Tap "+" (top right) > New repository. Name: stock-harness. Choose Public.
   Check "Add a README file" so the repo isn't empty. Tap Create repository.
5. In the new repo, tap Add file > Upload files > choose your files.
6. In the picker, open the stock-harness folder, tap Select > Select All, then Open.
   (Hidden files like .gitignore may not show. That's OK; you can add it later with Add file > Create new file.)
7. Our README.md will replace GitHub's starter one. Type a message like "Stock harness, sessions 1-10" and tap Commit changes.
8. Check: open the repo link in a private tab. You should see the README with the 7-part table.
9. Copy the link (github.com/YOUR-NAME/stock-harness) to your resume and LinkedIn.
Before uploading: never add passwords, keys, or personal info. This project has none.
